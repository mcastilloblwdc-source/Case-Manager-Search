TCB Case Manager Guide Finder

This GitHub Pages package searches the full text of three source references:
- TCB Program Management Guide, revised October 23, 2026
- SNAP 50/50 Case Manager Guide
- Apricot database how-to Google Doc

Files to upload to the repository root:
- index.html
- guidance-data.json
- assets/tec-centro-berks-logo.png
- .nojekyll

Keep index.html, guidance-data.json, and the assets folder at the same level. The app searches only the included source text and shows the matching guide and section. It does not generate new policy. A website-request contact schedule discrepancy in the program guide is flagged in search results.

This package includes staff-reference content from internal operating guides. A free GitHub Pages repository is public, so only publish it if that exposure is approved. If the repository already contains the sample demo, replace index.html, add guidance-data.json, and upload the assets folder.
