TCB Case Manager Guide Finder

This GitHub Pages package searches and labels four source sets:
- TCB Program Management Guide, revised October 23, 2026
- SNAP 50/50 Case Manager Guide
- Apricot database how-to Google Doc
- 19 reference entries summarized from public teccentroberks.org program pages

Files in the repository root:
- index.html
- guidance-data.json
- assets/tec-centro-berks-logo.png
- .nojekyll

Keep index.html, guidance-data.json, and the assets folder together at the repository root. Search results show the source and section; Apricot and public website entries link to their source pages. The finder returns passages and does not create new policy. It flags a website-request contact schedule discrepancy in the program guide.

Public website summaries may be general or change. Confirm exact eligibility, documents, fees, class schedule, tests, and current openings with a case manager.

This package includes staff-reference content from internal operating guides. A free GitHub Pages repository is public, so only publish it if that exposure is approved.
